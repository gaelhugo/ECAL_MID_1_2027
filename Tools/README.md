# Tools — Teaching & Experimentation Utilities

Utilities built for the course. Each subfolder is an independent project with its own `package.json`.

## Contents

| Folder                                                 | Description                                                                                                                                                                                                                                                                                                                                                                |
| ------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`AgentCodingWithLMStudio/`](AgentCodingWithLMStudio/) | "Atelier prompts webcam" — a step-by-step teaching app ("processus") where each step pairs a natural-language prompt (French) with the creative-coding code it produces. Demo processus are simple JSON files; modified prompts are regenerated by local LM Studio (default) or a free online model chosen in the ⚙︎ settings (Google AI Studio, Groq, Mistral, OpenRouter) |
